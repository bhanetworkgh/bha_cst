### Session 3 — Production Hardening & Pakistan Route Closure

**Goal:** Validate permanent-failure error-code handling, add voice and delivery-callback tests, close remaining gaps.

**Bugs fixed:**

1. **Missing non-retriable Twilio error codes** — `21215`, `30005`, `30008` were absent from `TwilioClientWrapper.nonRetriableErrorCodes`. Without these, geo-permission failures and carrier rejections would exhaust 3 retry attempts before being marked permanently failed, wasting Twilio API quota.

2. **Error code missing from stored `error_message`** — `lastError` was set to `err.message` only. Operator had to correlate log output to find the error code. Changed to `"<code>: <message>"` so the database record is self-diagnosing.

**Architecture clarification documented:**

- CST's voice lane is an **inbound synthesis pipeline** (no `twilio.calls.create()`). Twilio error `21215` (geo-permission denied) can only surface on the **SMS outbound queue** — not on the ElevenLabs synthesis path. This was documented and anchored in the test record to prevent future misclassification.
