#### 1.2 Security Hardening — `readBearer()` Fix

Gap found in `vfarm_proxy_auth.ts`: an `Authorization: Bearer ` header with trailing whitespace only would return non-null, potentially bypassing the null-credential guard. Fixed:

- Trimmed inner token after regex match; returns `null` on empty result.
- Added guard for bare `"bearer"` literal (previously passed as a token value).

No legitimate token parsing was changed.

#### 1.3 Security Bypass Regression Tests (18 → 24 tests)

Added 6 new bypass-vector tests to `tests/security/vfarm_proxy_unauth.test.ts`:

| Test | Vector Covered |
|:-----|:--------------|
| Query-param token injection on `/api/tokens` | `?token=<jwt>` must not be treated as a credential |
| Query-param token injection on `/api/devices` | Same for admin-only device route |
| Query-param `x-admin-token` injection | Must not bypass header requirement |
| Empty / whitespace-only Bearer credential | `Authorization: Bearer ` treated as unauthenticated |
| Caller JWT + valid admin session on admin-only routes | Never forwards caller JWT upstream |
| Caller JWT + expired admin session on admin-only routes | Returns 401 or 403, 0 upstream calls |
