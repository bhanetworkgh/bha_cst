### 2.2 Core Code Diff Breakdown

#### 🔐 Security: `engine/src/middleware/vfarm_proxy_auth.ts`
* **Before:**
  ```typescript
  function readBearer(req: Request): string | null {
    const header = req.header('authorization');
    if (!header) return null;
    const match = /^Bearer\s+(.+)$/i.exec(header.trim());
    const raw = match ? match[1] : header.trim();
    return raw ? raw.trim() : null; // "Bearer   " passed through as truthy
  }
  const sessionToken = req.header('x-admin-token'); // Not trimmed
  ```
* **After:**
  ```typescript
  function readBearer(req: Request): string | null {
    const header = req.header('authorization');
    if (!header) return null;
    const trimmed = header.trim();
    if (!trimmed) return null;
    const match = /^Bearer\s+(.+)$/i.exec(trimmed);
    if (match) {
      const raw = match[1].trim();
      return raw.length > 0 ? raw : null; // Empty after trim rejected
    }
    if (trimmed.toLowerCase() === 'bearer') return null; // Bare literal rejected
    return trimmed;
  }
  const sessionToken = (req.header('x-admin-token') || '').trim(); // Trimmed in both middlewares
  ```

#### ✉️ Consent & Regulatory: `wording.ts`, `service.ts`, `interfaces/sms/index.ts`
* **Before:** Missing `HELP` / `INFO` keywords; consent status fetched late in the pipeline inside affirmative branch.
* **After:**
  * Added `HELP_KEYWORDS` (`help`, `info`), `HELP_RESPONSE_TEXT`, and `isHelpMessage()`.
  * Added `handleInboundHelpMessage()` responding with regulatory copy under `consent_exempt: true`.
  * Inbound SMS router checks `STOP` and `HELP` before all other processing; retrieves consent status upfront; strictly drops any non-consented traffic from opted-out numbers.

#### 🗄️ Database Migrations: `017_sms_consent_audit_fk.sql` & `018_sms_consent_prompts.sql`
* **Before:** Single-column FK with subquery `CHECK` in `017`; partial indexes with `WHERE expires_at > NOW()` in `018`.
* **After:** Composite unique index and composite FK `(consent_id, tenant_id)` in `017` with trigger-enforced append-only audit immutability; unconditional unique index in `018` for clean prompt upserts.

#### ☁️ Deployment: `render.yaml`
* **Before:** Free-tier defaults without `preDeployCommand` separation or migration guidance.
* **After:** Explicit `preDeployCommand: node scripts/migrate.js` for paid plans; fallback in `startCommand` for free plan; comprehensive operational comments documenting the 15-minute hibernation cold-wake 503 error (`x-render-routing: hibernate-wake-error`).
