All API endpoints are under /api/v1/admin and require a session cookie from POST /api/v1/auth/login.

Register a Speaker (Your Number)
POST /api/v1/admin/speakers Body (JSON): { "phone_e164": "+15551234567", // your number in E.164 "customer_ref": "your-name-id", // unique ID for you "tenant_id": "tenant-vfarm-01", "project_id": "proj-vfarm-main", "role": "owner", // owner | manager | tech "farm_ids": [], // optional farm scoping "ttl_hours": 48 // cache TTL } Response 201: { "status": "created", "speaker": { ... } }
List Speakers
GET /api/v1/admin/speakers?tenant_id=tenant-vfarm-01&project_id=proj-vfarm-main Response 200: { "speakers": [...], "count": N }
Bind a Service Number (DID → Project)
POST /api/v1/admin/numbers/bind Body (JSON): { "phone_e164": "+19715885826", // the Twilio number callers dial "tenant_id": "tenant-vfarm-01", "project_id": "proj-vfarm-main", "capability": "voice" // voice | sms } Response 201: { "status": "bound", "binding": { ... } }
View All Bindings
GET /api/v1/admin/numbers/bindings Response 200: { "bindings": [...], "count": N }
Login (get session cookie)
POST /api/v1/auth/login Body (JSON): { "email": "you@example.com", "password": "yourpassword" } Response 200: { "status": "ok", "token": "..." } → Sets Set-Cookie: cst_session=... → Include this cookie on all subsequent /admin/* requests
cURL Examples
# 1. Login and save cookies curl -c cookies.txt -X POST \ https://bha-cst-7u9e.onrender.com/api/v1/auth/login \ -H 'Content-Type: application/json' \ -d '{"email":"admin@example.com","password":"yourpass"}' # 2. Register your number as a speaker curl -b cookies.txt -X POST \ https://bha-cst-7u9e.onrender.com/api/v1/admin/speakers \ -H 'Content-Type: application/json' \ -d '{ "phone_e164":"+15551234567", "customer_ref":"my-test-id", "tenant_id":"tenant-vfarm-01", "project_id":"proj-vfarm-main", "role":"owner", "farm_ids":[], "ttl_hours":48 }' # 3. Check current bindings curl -b cookies.txt \ https://bha-cst-7u9e.onrender.com/api/v1/admin/numbers/bindings # 4. Bind a DID to a project (if not already bound) curl -b cookies.txt -X POST \ https://bha-cst-7u9e.onrender.com/api/v1/admin/numbers/bind \ -H 'Content-Type: application/json' \ -d '{ "phone_e164":"+19715885826", "tenant_id":"tenant-vfarm-01", "project_id":"proj-vfarm-main", "capability":"voice" }'
